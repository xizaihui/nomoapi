# OpenToken (New API) — Per-Company Pricing Visibility

## Context
- Project: OpenToken / New API (fork of QuantumNous/new-api)
- Local path: `/opt/apps/newapis`
- Remote path: `/opt/apps/opentoken`
- Stack: Go backend + React frontend (migrating Semi UI → shadcn/ui)
- User preference: minimal-change solutions (方案A)

## Task
Hide group ratio info from non-admin users on the model pricing page. Each company/user should only see their own group's pricing; admins still see all groups.

## Changes Made

### Backend: `controller/pricing.go`
- In the pricing handler, detect current user's group and admin status.
- Use `model.GetUserCache(userId)` to get `user.Group`.
- Use `model.IsAdmin(userId)` (instead of `user.Role >= common.RoleAdminUser`) for admin check — more reliable since `TryUserAuth` context may not populate role.
- Non-admins: filter pricing response to only include their own group's ratios.
- Admins: return full group ratio map as before.
- Removed unused `common` import after switching to `model.IsAdmin`.

## Build / Deploy Notes
- Frontend build: `cd /opt/apps/newapis/web && npm run build`
- Build is slow (~2-3 min) and memory-hungry; use `NODE_OPTIONS='--max-old-space-size=4096'` to avoid OOM on 8GB host.
- Host has 7.8Gi RAM, 4Gi swap; ~5Gi typically available during build.
- Build output: `/opt/apps/newapis/web/dist/` (check `index.html` mtime to verify fresh build).
- Don't launch multiple concurrent `npm run build` — they conflict and can leave dist stale.
