# 2026-04-13 工作日志

## ClewdR — Tool Simulation 加固 (Plan A+C)

### 背景
clewdr 通过 tool simulation 让 claude.ai 网页端支持 tool use（API 级别）。
之前偶尔出现 Claude 不按 sentinel 格式输出导致工具调用失败。

### 实现内容
**分支**: `feat/tool-sim-hardening`  
**Commit**: `477a019`  
**已部署**: 38.150.32.190

#### Plan A — force_tool 系统提示约束
- `tool_choice=any/tool` 时，system prompt 末尾追加强制约束
- "⚠️ MANDATORY: You MUST call a tool" — 逼 Claude 输出 sentinel 格式
- 改动文件: `tool_protocol.rs` (`build_tool_prompt` 加 `force_tool` 参数)

#### Plan C — 四层解析 fallback 链
1. 精确 sentinel 匹配（原有）
2. 模糊 sentinel 匹配（容忍 Claude 微改 sentinel，用 req_id+nonce 高熵锚点）
3. XML `<tool_call>` fallback（兼容旧格式）
4. 裸 JSON `{"name":"...","arguments":{...}}` 兜底检测

#### 增强
- `parse_sentinel_body_inner()` — JSON 提取增强，body 中有额外文本时也能提取
- `parse_fuzzy_sentinel_tool_calls()` — 容忍 Unicode 括号变体、空格、大小写
- `parse_bare_json_tool_calls()` — 匹配已注册工具名的裸 JSON

### 端到端测试结果
- ✅ 标准 auto tool call
- ✅ tool_choice=any 强制调用（"Hello" 也调工具）
- ✅ Streaming 模式
- ✅ 多轮 tool_result 上下文
- ✅ 86 单元测试全通过

### 注意
- assistant prefill 在 claude.ai `/completion` 端点无效（flat prompt，不是 messages 数组）
- 最终方案是在 system prompt 里加强约束，而不是 prefill
- 二进制大小不变 ~17.6MB
