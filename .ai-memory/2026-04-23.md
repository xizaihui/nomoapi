### 下午续 — 服务器升级 + 图片流程重构

8. **服务器升级**: 1.9GB/1核 → 8GB/4核 AMD EPYC 9754，所有服务自动启动确认（systemd linger + enabled）

11. **最终方案 — 关闭图片理解**:
    - `tools.media.image.enabled: false` — gateway 收到图片只保存文件，不发给模型

### 晚间 — inbound.ts 补丁 + 图片理解脚本 + 异步进度

13. **inbound.ts 补丁**: 即使 `tools.media.image.enabled: false`，gateway 收到图片仍设 `ctx.MediaPath` 导致 core pipeline 卡死。补丁位置 `weixinMessageToMsgContext`：不再设 `ctx.MediaPath`/`ctx.MediaType`，改为把路径嵌入 `ctx.Body` 为 `[图片已保存: /path/to/xxx.jpg]`。备份在 `inbound.ts.bak`。
14. **describe_image.py**: 独立图片理解脚本，直接调 gpt-5.4 vision API（绕过 gateway 图片管道），agent 需要看图时手动调用
15. **weixin_send.py**: 直接调微信 iLink API 发文字消息（毫秒级），绕过 openclaw CLI（每次启动 Node 进程太慢）。凭据从 `/root/.openclaw/openclaw-weixin/accounts/` 读取
16. **generate_image.py 重写**: 进度消息改用 weixin_send.py 直接发（秒到），平滑进度条（每 5s 递增、每 10s 推送），图片发送 timeout 120s，失败时 fallback 发预览链接
17. **AGENTS.md 更新**: agent 不再发进度文字（"正在生成"/"生成好了"），全部由脚本处理；收到图片+文字时跳过 describe_image 直接生成
