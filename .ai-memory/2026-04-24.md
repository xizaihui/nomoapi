24. **aes_key 编码修复（灰色空白块根因）**:
    - Node.js: `Buffer.from(hexString).toString("base64")` — base64 编码的是 hex 字符串的 UTF-8 字节（32字节）
    - Go 原来: `base64.StdEncoding.EncodeToString(rawBytes)` — base64 编码的是原始 16 字节
    - 微信客户端拿到错误 key → 解密失败 → 显示灰色空白块
    - 修复: `sendImageMessage` 参数改为传 `aesKeyHex string`，`base64.StdEncoding.EncodeToString([]byte(aesKeyHex))`
25. **CDN 上传重试 + HTTP 回退**:

### 踩过的坑（新增）
- **CDN 错误码 -5104001**: 微信 CDN 间歇性 500，可能跟文件大小/加密有关，压缩后好转
- **aes_key 编码差异**: Node.js 的 `Buffer.from(hex)` 是把 hex 当 UTF-8 字符串（32字节），不是解码为原始字节（16字节）— 这个差异导致图片显示为灰块
